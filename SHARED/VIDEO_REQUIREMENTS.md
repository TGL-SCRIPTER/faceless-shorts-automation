# Video requirements

## Confirmed
- Daily batch: 3 Shorts.
- Claude: 1; OpenCode: 1; Codex: 1 only if available.
- **Animation: genuine 2D only; never 3D.**
- All six Faceless Shorts skill styles may be used. Deep Dive, Night File, and Tall Tale must be redesigned as genuine 2D before production.
- No duplicate or substantially overlapping topics, angles, hooks, story structures, or primary styles.
- Claude voice must differ from OpenCode; aim for three distinct presets.
- Public description includes a labelled Sources section with source names/publishers only; no URLs.
- Upload only after all three pass validation.
- Prefer existing access and free/local tools; no paid API or subscription without approval.

## Settings to confirm (do not guess)
- Language and target duration
- Aspect ratio (9:16 recommended for Shorts), resolution, frame rate
- Caption style and placement
- Voice provider and exact preset for each agent
- Music/SFX source and licensing policy
- Storage accessible to Zapier
- YouTube channel/account
- Upload privacy and publishing schedule/time zone
- Whether human approval is required before public publishing

## Per-video checklist
- [ ] File exists and plays.
- [ ] Genuine 2D animation only; no 3D models, renders, geometry, or environments.
- [ ] Any 3D-origin style has a documented 2D conversion plan.
- [ ] Vertical framing and readable captions.
- [ ] Topic, angle, hook, structure, and visual style are distinct.
- [ ] Voice preset recorded and voice separation satisfied.
- [ ] Accurate title and sectioned description.
- [ ] Sources section has names only, no URLs.
- [ ] Claims and sources checked.
- [ ] Asset rights documented.
