# Style library

## Priority
Use the installed Faceless Shorts skill's ideas, templates, formats, styles, and production methods first. All six catalogue styles are available, subject to the strict 2D conversion rule in `SKILL_INTEGRATION.md`.

## Skill styles
- `inside-out` — native 2D flat illustrated explainers.
- `stick-story` — native 2D stick-figure storytelling.
- `paper-atlas` — native 2D cut-paper scenes and maps.
- `deep-dive` — cinematic documentary style, converted to layered 2D illustration and motion graphics.
- `night-file` — mystery/noir style, converted to 2D illustrated scenes, silhouettes, documents, and maps.
- `tall-tale` — character-led storytelling, converted to fully 2D characters and environments.

## Storytelling formats
- Mini-documentary
- Curiosity / mystery with an evidence-based reveal
- Timeline
- Myth vs fact
- Counted sequence
- How-it-works explainer
- Unexpected connection
- Analogy explainer (clarify analogy limits)

## Additional 2D visual treatments
- Flat vector character animation
- Cut-paper / collage animation
- 2D motion-graphics infographic
- Hand-drawn frame-by-frame look
- 2D map and timeline animation
- Silhouette and shape-based storytelling
- Comic-panel transitions
- Whiteboard-style 2D diagrams

## Batch variation
Coordinator assigns different primary storytelling formats and dominant visual treatments within each batch where feasible. Check recent history to avoid repetitive combinations. A style's 3D origin does not permit 3D output; convert it to genuine 2D.
