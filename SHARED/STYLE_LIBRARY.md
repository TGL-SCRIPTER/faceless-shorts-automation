# Style library

## Priority
Use the installed Faceless Shorts skill's own ideas and style catalog first. This list is fallback vocabulary only. Every result remains 2D animation.

## Storytelling formats
- Mini-documentary
- Curiosity / mystery with an evidence-based reveal
- Timeline
- Myth vs fact
- Counted sequence
- How-it-works explainer
- Unexpected connection
- Analogy explainer (clarify analogy limits)

## 2D visual treatments
- Flat vector character animation
- Cut-paper / collage animation
- 2D motion-graphics infographic
- Hand-drawn frame-by-frame look
- 2D map and timeline animation
- Silhouette and shape-based storytelling
- Comic-panel transitions
- Whiteboard-style 2D diagrams

## Batch variation
Coordinator assigns different primary storytelling formats and dominant visual treatments within each batch where feasible. Check recent history to avoid repetitive combinations. Skill-provided styles take priority.
